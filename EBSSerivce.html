AWS EBS

☁️ AWS EBS — Elastic Block Store

Complete notes: concepts, workflows, and a hands-on beginner task list

AWS EBS (Elastic Block Store) is a cloud-based storage service that provides durable, high-performance block storage for use with Amazon EC2 instances.

It works like a virtual hard drive, allowing you to store and access data even when your EC2 instances are stopped or terminated.

Example

If you are hosting a MySQL or PostgreSQL database, you need reliable, high-performance storage to handle frequent read/write operations. EBS provides persistent, fast storage that ensures your data is saved even if the EC2 instance is stopped or restarted — making it ideal for database workloads.

🔑 Key Points of AWS EBS

  • Persistent Storage — Data remains available even when the EC2 instance is stopped.
  • Block Storage — Works like a virtual hard drive attached to an EC2 instance.
  • High Performance — Supports fast read/write operations.
  • Durable — Designed to keep your data reliably stored.
  • Scalable — Volume size can be increased as storage requirements grow.
  • Snapshots — You can create backups of EBS volumes using snapshots.
  • Attach/Detach — An EBS volume can be attached to or detached from EC2 instances.
  • Availability Zone — An EBS volume is tied to a specific Availability Zone.
  • Database Workloads — Suitable for MySQL, PostgreSQL, and other apps needing persistent storage.

🛠️ Create EBS Volume & Attach to EC2

Steps to Create EBS Volume

  1. Go to the EC2 Dashboard.
  2. On the left side, go to Elastic Block Store → Volumes.
  3. Click Create volume.
  4. Select the required Volume Type.
  5. Enter the required Size of the volume.
  6. Select the same Availability Zone as your EC2 instance.
  7. Click Create volume.

Steps to Attach EBS Volume to EC2

  1. Go to Elastic Block Store → Volumes.
  2. Select the newly created EBS volume.
  3. Click Actions → Attach volume.
  4. Select your EC2 instance.
  5. Select the required Device name.
  6. Click Attach volume.
  7. The EBS volume is now attached to your EC2 instance.

Verify the Volume

Connect to your EC2 instance using SSH and run:

lsblk

📈 Modify EBS Volume Size

You can increase the storage size of an existing EBS volume when you need more space.

  1. Go to the EC2 Dashboard.
  2. On the left side, go to Elastic Block Store → Volumes.
  3. Select the EBS volume you want to modify.
  4. Click Actions → Modify volume.
  5. Increase the Size according to your requirement.
  6. Click Modify.
  7. Confirm the modification.
  8. Check the volume status until it becomes In-use and the modification is completed.
  9. Connect to your EC2 instance and run: lsblk

🔌 Detach and Delete EBS Volume

You can detach an EBS volume from an EC2 instance and then delete it when you no longer need it.

Steps to Detach EBS Volume

  1. Go to the EC2 Dashboard.
  2. On the left side, go to Elastic Block Store → Volumes.
  3. Select the EBS volume you want to detach.
  4. Click Actions → Detach volume.
  5. Confirm the detachment.
  6. Wait until the volume state changes from In-use to Available.

Steps to Delete EBS Volume

  1. Select the EBS volume with the Available state.
  2. Click Actions → Delete volume.
  3. Confirm the deletion.
  4. The EBS volume will be permanently deleted.
Note: Deleting an EBS volume permanently removes the data stored on that volume. If you need the data later, create an EBS Snapshot before deleting the volume.

📸 Create EBS Snapshot

An EBS Snapshot is a backup of an EBS volume. You can use the snapshot to create a new EBS volume.

Steps to Create Snapshot

  1. Go to the EC2 Dashboard.
  2. On the left side, go to Elastic Block Store → Volumes.
  3. Select the EBS volume you want to back up.
  4. Click Actions → Create snapshot.
  5. Enter a Description for the snapshot.
  6. Click Create snapshot.
  7. Go to Elastic Block Store → Snapshots to check the snapshot.

♻️ Create EBS Volume from Snapshot

  1. Go to EC2 Dashboard.
  2. On the left side, go to Elastic Block Store → Snapshots.
  3. Select the snapshot you want to use.
  4. Click Actions → Create volume from snapshot.
  5. Select the required Volume Type.
  6. Enter the required Size.
  7. Select the Availability Zone where your EC2 instance is running.
  8. Click Create volume.

Attach the New EBS Volume to an EC2 Instance

  1. Go to Elastic Block Store → Volumes.
  2. Select the volume created from the snapshot.
  3. Click Actions → Attach volume.
  4. Select the EC2 instance.
  5. Select the required Device name.
  6. Click Attach volume.
  7. Connect to the EC2 instance and run: lsblk

🌍 Attach EBS Volume Across Regions

You cannot directly attach an EBS volume from one AWS Region to an EC2 instance in another Region.

To use the same data in another Region, you need to create a snapshot, copy the snapshot to the other Region, create a new volume, and attach it to the EC2 instance.

  1. Go to the EC2 Dashboard in the source Region.
  2. Go to Elastic Block Store → Volumes.
  3. Select the EBS volume you want to move.
  4. Click Actions → Create snapshot.
  5. Enter a Description and click Create snapshot.
  6. Go to Elastic Block Store → Snapshots.
  7. Select the snapshot.
  8. Click Actions → Copy snapshot.
  9. Select the Destination Region.
  10. Click Copy snapshot.
  11. Switch to the Destination Region.
  12. Go to Elastic Block Store → Snapshots.
  13. Select the copied snapshot.
  14. Click Actions → Create volume from snapshot.
  15. Select the same Availability Zone as the EC2 instance.
  16. Enter the required Volume Type and Size.
  17. Click Create volume.
  18. Go to Elastic Block Store → Volumes.
  19. Select the newly created EBS volume.
  20. Click Actions → Attach volume.
  21. Select the EC2 instance in the destination Region.
  22. Select the required Device name.
  23. Click Attach volume.
  24. Connect to the EC2 instance and run: lsblk
