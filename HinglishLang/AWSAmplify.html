THEORY 1. AWS Amplify Kya Hai?

"AWS Amplify AWS ka ek all-in-one platform hai jo full-stack web aur mobile applications ko tezi se build, host aur connect karne ke liye ready-made tools, libraries aur hosting services provide karta hai — bina individual AWS services ko manually configure kiye."

Pehle agar aapko ek React app deploy karni hoti thi, toh aapko alag se S3 bucket banana, CloudFront CDN connect karna, SSL certificate configure karna, Cognito User Pool banana aur API Gateway set karna padta tha. Amplify in saari complex services ko ek single, automated workflow mein wrap kar deta hai!

PRACTICAL 7. PRACTICAL: React/Vite App Ko Amplify Par Deploy Karein

Step-by-Step Practical Approach:

  1. Step 1: Local React App Banayein:
    Terminal
    npm create vite@latest my-amplify-app -- --template react
cd my-amplify-app
npm install
npm run dev
  2. Step 2: GitHub Par Code Push Karein:
    Git Terminal
    git init
git add .
git commit -m "feat: initial commit for Amplify"
git branch -M main
git remote add origin https://github.com/<your-username>/my-amplify-app.git
git push -u origin main
  3. Step 3: AWS Amplify Console Open Karein:
    • AWS Console mein Amplify search karein.
    • Host web app par click karein → GitHub select karein → Click Next.
    • Apna GitHub repository (my-amplify-app) aur main branch select karein.
  4. Step 4: Build Settings Check Karein: Amplify automatically Vite ko detect karke build directory dist set kar dega. Click Save and deploy.
  5. Step 5: Live URL Par Check Karein: Build complete hone par Amplify aapko live HTTPS URL dega (e.g. https://main.d1234abcd.amplifyapp.com).

THEORY 8 & 9. Build Settings (amplify.yml) & Environment Variables

amplify.yml File Structure:

YAML
version: 1
frontend:
  phases:
    preBuild:
      commands:
        - npm ci
    build:
      commands:
        - npm run build
  artifacts:
    baseDirectory: dist     # Vite ke liye 'dist', CRA ke liye 'build'
    files:
      - '**/*'
  cache:
    paths:
      - node_modules/**/*
🔒 Frontend Env Variables Security:

Vite mein VITE_ se shuru hone wale variables browser ke JavaScript code mein embed ho jaate hain. Isliye database password ya secret keys frontend env mein KABHI BHI na dalein!

THEORY 10 & 11. Authentication & Amazon Cognito

  • Cognito User Pool (Authentication): User login, signup, password reset aur JWT tokens (ID Token, Access Token) issue karta hai.
  • Cognito Identity Pool (Authorization): Logged-in user ko temporary AWS IAM credentials deta hai taaki wo directly S3 bucket mein image upload kar sake.

TROUBLESHOOTING 28 & 29. 10 COMMON AMPLIFY ERRORS & FIXES

Problem / Error Karan (Root Cause) Solution (Kaise Fix Karein)
1. Build Step Failed package.json mein missing dependency ya syntax error. Amplify console build logs check karein; local par npm run build run karein.
2. Blank White Screen on Live App amplify.yml mein galat baseDirectory set hai. Vite ke liye baseDirectory: dist karein (CRA ke liye build).
3. Refresh karne par 404 Error SPA client routing ke liye server rewrite missing hai. Amplify Rewrites mein 200 Rewrite rule add karein targeting /index.html.
4. Browser CORS Error Backend server Amplify domain ko allow nahi kar raha. Backend Express app mein CORS whitelist mein Amplify URL add karein.
5. Env Variable Undefined Variable mein VITE_ prefix missing hai ya app rebuild nahi hui. Variable name VITE_API_URL karein aur app ko rebuild karein.

IMPORTANT 30. REACT SPA ROUTING (404 ON REFRESH FIX)

Problem: React Router client-side routing karta hai. Jab user /dashboard par refresh karta hai, toh server par aisi koi physical file nahi milti aur 404 Not Found error aa jata hai.

Fix: Amplify Console Mein 200 Rewrite Rule Lagayein:

  1. Amplify Console → App settings → Rewrites and redirects par click karein.
  2. Add rule par click karein:
    • Source address: </^[^.]+$|\.(?!(css|gif|ico|jpg|js|png|txt|svg|woff|woff2|ttf|map|json)$)([^.]+$)/>
    • Target address: /index.html
    • Type: 200 (Rewrite)
  3. Click Save. Ab saare routes smoothly render honge!

INTERVIEW 37. TOP 30+ AWS AMPLIFY INTERVIEW QUESTIONS & ANSWERS

Q1. AWS Amplify kya hai?

AWS ka ek platform jo full-stack web aur mobile apps ko automated CI/CD aur serverless backends ke sath fast build aur deploy karne deta hai.

Q2. Amplify Hosting aur S3 Hosting mein kya farak hai?

Amplify Hosting mein automated Git CI/CD, free SSL, CloudFront CDN aur SPA rewrites built-in milte hain, jabki S3 mein ye sab manually configure karna padta hai.

Q3. Amplify Hosting ke peeche kaunsa CDN kaam karta hai?

Amazon CloudFront jo global edge locations par static assets cache karta hai.

Q4. React app refresh karne par 404 kyun aata hai?

Kyunki client-side route server par physically exist nahi karta; ise fix karne ke liye 200 Rewrite rule lagaya jata hai jo traffic ko /index.html par bhejta hai.

Q5. Cognito User Pool aur Identity Pool mein kya farak hai?

User Pool authentication (user login/JWTs) ke liye hai; Identity Pool authorization (AWS IAM credentials for S3) ke liye hai.

REVISION 39. QUICK REVISION CHEAT SHEET

  • Amplify Hosting = Git-driven serverless frontend hosting with CloudFront CDN & SSL.
  • Vite baseDirectory = dist (in amplify.yml).
  • SPA 404 Solution = 200 Rewrite rule in Rewrites and Redirects.

  • Cognito Identity Pool = S3 direct upload IAM credentials.
  • Amplify Storage = S3 bucket abstraction.
