☁️ AWS EBS — Elastic Block Store

Complete notes: concepts, workflows, aur ek hands-on beginner task list

AWS EBS (Elastic Block Store) ek cloud-based storage service hai jo Amazon EC2 instances ke saath use karne ke liye durable, high-performance block storage provide karti hai.

Ye ek virtual hard drive ki tarah kaam karti hai, jisse aap data store aur access kar sakte ho — chahe aapke EC2 instances stopped ya terminated hi kyu na hon.

Example

Agar aap MySQL ya PostgreSQL database host kar rahe ho, to frequent read/write operations handle karne ke liye reliable, high-performance storage chahiye. EBS persistent, fast storage deta hai jo ensure karta hai ki EC2 instance stop ya restart hone pe bhi data safe rahe — isliye database workloads ke liye ideal hai.

🔑 AWS EBS Ke Key Points

  • Persistent Storage — EC2 instance stop hone pe bhi data available rehta hai.
  • Block Storage — EC2 instance se attached virtual hard drive ki tarah kaam karta hai.
  • High Performance — Fast read/write operations support karta hai.
  • Durable — Data ko reliably store rakhne ke liye design kiya gaya hai.
  • Scalable — Storage requirement badhne pe volume size increase kiya ja sakta hai.
  • Snapshots — Snapshots use karke EBS volumes ke backups bana sakte ho.
  • Attach/Detach — EBS volume ko EC2 instances se attach/detach kiya ja sakta hai.
  • Availability Zone — Ek EBS volume ek specific Availability Zone se tied hota hai.
  • Database Workloads — MySQL, PostgreSQL, aur persistent storage chahne wale apps ke liye suitable.

🛠️ EBS Volume Create & EC2 Se Attach Karna

EBS Volume Create Karne Ke Steps

  1. EC2 Dashboard pe jao.
  2. Left side pe Elastic Block Store → Volumes pe jao.
  3. Create volume pe click karo.
  4. Required Volume Type select karo.
  5. Volume ka required Size daalo.
  6. Apne EC2 instance jaisi hi Availability Zone select karo.
  7. Create volume pe click karo.

EBS Volume Ko EC2 Se Attach Karne Ke Steps

  1. Elastic Block Store → Volumes pe jao.
  2. Newly created EBS volume select karo.
  3. Actions → Attach volume pe click karo.
  4. Apna EC2 instance select karo.
  5. Required Device name select karo.
  6. Attach volume pe click karo.
  7. Ab EBS volume aapke EC2 instance se attach ho chuka hai.

Volume Verify Karna

SSH se apne EC2 instance se connect karo aur ye run karo:

lsblk

📈 EBS Volume Size Modify Karna

Zyada space chahiye ho to existing EBS volume ki storage size badha sakte ho.

  1. EC2 Dashboard pe jao.
  2. Left side pe Elastic Block Store → Volumes pe jao.
  3. Jo EBS volume modify karna hai use select karo.
  4. Actions → Modify volume pe click karo.
  5. Apni zarurat ke hisaab se Size badhao.
  6. Modify pe click karo.
  7. Modification confirm karo.
  8. Volume status In-use hone tak check karte raho, jab tak modification complete na ho jaye.
  9. EC2 instance se connect karke run karo: lsblk

🔌 EBS Volume Detach Aur Delete Karna

Zarurat na ho to EBS volume ko EC2 instance se detach karke phir delete kiya ja sakta hai.

EBS Volume Detach Karne Ke Steps

  1. EC2 Dashboard pe jao.
  2. Left side pe Elastic Block Store → Volumes pe jao.
  3. Jo EBS volume detach karna hai use select karo.
  4. Actions → Detach volume pe click karo.
  5. Detachment confirm karo.
  6. Volume state In-use se Available hone tak wait karo.

EBS Volume Delete Karne Ke Steps

  1. Available state wala EBS volume select karo.
  2. Actions → Delete volume pe click karo.
  3. Deletion confirm karo.
  4. EBS volume permanently delete ho jaayega.
Note: EBS volume delete karne se us volume pe stored data permanently remove ho jaata hai. Agar data baad mein chahiye ho, to volume delete karne se pehle ek EBS Snapshot bana lo.

📸 EBS Snapshot Create Karna

Ek EBS Snapshot ek EBS volume ka backup hota hai. Aap snapshot use karke naya EBS volume bhi bana sakte ho.

Snapshot Create Karne Ke Steps

  1. EC2 Dashboard pe jao.
  2. Left side pe Elastic Block Store → Volumes pe jao.
  3. Jo EBS volume backup karna hai use select karo.
  4. Actions → Create snapshot pe click karo.
  5. Snapshot ke liye Description daalo.
  6. Create snapshot pe click karo.
  7. Snapshot check karne ke liye Elastic Block Store → Snapshots pe jao.

♻️ Snapshot Se EBS Volume Create Karna

  1. EC2 Dashboard pe jao.
  2. Left side pe Elastic Block Store → Snapshots pe jao.
  3. Jo snapshot use karna hai use select karo.
  4. Actions → Create volume from snapshot pe click karo.
  5. Required Volume Type select karo.
  6. Required Size daalo.
  7. Jis Availability Zone mein aapka EC2 instance chal raha hai wahi select karo.
  8. Create volume pe click karo.

Naye EBS Volume Ko EC2 Instance Se Attach Karna

  1. Elastic Block Store → Volumes pe jao.
  2. Snapshot se banaya gaya volume select karo.
  3. Actions → Attach volume pe click karo.
  4. EC2 instance select karo.
  5. Required Device name select karo.
  6. Attach volume pe click karo.
  7. EC2 instance se connect karke run karo: lsblk

🌍 EBS Volume Cross Regions Attach Karna

Aap ek AWS Region ka EBS volume directly doosre Region ke EC2 instance se attach nahi kar sakte.

Same data doosre Region mein use karne ke liye snapshot banana, us snapshot ko doosre Region mein copy karna, naya volume banana, aur usse EC2 instance se attach karna padta hai.

  1. Source Region mein EC2 Dashboard pe jao.
  2. Elastic Block Store → Volumes pe jao.
  3. Jo EBS volume move karna hai use select karo.
  4. Actions → Create snapshot pe click karo.
  5. Description daalo aur Create snapshot pe click karo.
  6. Elastic Block Store → Snapshots pe jao.
  7. Snapshot select karo.
  8. Actions → Copy snapshot pe click karo.
  9. Destination Region select karo.
  10. Copy snapshot pe click karo.
  11. Destination Region pe switch karo.
  12. Elastic Block Store → Snapshots pe jao.
  13. Copied snapshot select karo.
  14. Actions → Create volume from snapshot pe click karo.
  15. EC2 instance jaisi hi Availability Zone select karo.
  16. Required Volume Type aur Size daalo.
  17. Create volume pe click karo.
  18. Elastic Block Store → Volumes pe jao.
  19. Newly created EBS volume select karo.
  20. Actions → Attach volume pe click karo.
  21. Destination Region mein EC2 instance select karo.
  22. Required Device name select karo.
  23. Attach volume pe click karo.
  24. EC2 instance se connect karke run karo: lsblk
