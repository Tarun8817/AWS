1. What is DNS (Domain Name System)? Theory

Simple Definition:
"DNS (Domain Name System) is the phonebook of the Internet. Humans access information online through domain names like google.com or amazon.com. Web browsers interact through Internet Protocol (IP) addresses like 142.250.190.46. DNS translates domain names to IP addresses so browsers can load internet resources."
WITHOUT DNS (Human Nightmare): Must memorize numbers: http://13.62.102.238, http://54.239.28.85 WITH DNS (Human Friendly): https://example.com ──► DNS Translation ──► 13.62.102.238 ──► Web Server

2 & 3. Anatomy of a Domain & How DNS Resolution Works Architecture

Anatomy of www.api.example.com.

  • Root Domain (.): The implicit dot at the very end of every fully qualified domain name.
  • Top-Level Domain (TLD) (.com): Managed by registries (e.g. Verisign for .com).
  • Second-Level Domain (SLD) (example): The unique domain name registered by an organization.
  • Subdomain (www / api): Specific prefixes created by the domain owner to route traffic.

The 8-Step DNS Lookup Journey:

=============================== STEP-BY-STEP DNS RESOLUTION =============================== [ User / Browser ] ──► (1) "What is the IP of example.com?" │ ▼ [ DNS Recursive Resolver ] (e.g., ISP DNS / 8.8.8.8) │ ├────► (2) Queries Root DNS Server (".") ─────────► Returns TLD Server IP (".com") │ ├────► (3) Queries TLD DNS Server (".com") ───────► Returns Authoritative NS (Route 53) │ └────► (4) Queries Authoritative Nameserver ──────► Returns Exact IP (13.62.102.238) │ ▼ [ Browser connects to IP 13.62.102.238 on Port 80/443 ] ──► Web Page Loaded! =============================================================================================

TTL (Time To Live) & DNS Caching:

TTL is a numerical value in seconds telling DNS resolvers how long to cache a DNS record locally before asking the authoritative nameserver again. A TTL of 300 means 5 minutes; a TTL of 86400 means 24 hours.

12 to 19. Amazon Route 53 & Hosted Zones Route 53

Amazon Route 53: AWS's highly available, scalable cloud DNS web service (designed on TCP/UDP Port 53) providing 100% availability SLA, domain registration, health checking, and latency-based global traffic routing.

Public vs Private Hosted Zones:

Feature Public Hosted Zone Private Hosted Zone
VisibilityInternet-wide (Accessible by anyone globally).Restricted strictly to one or more selected AWS VPCs.
Use CasePublic websites, mobile apps, APIs.Internal microservices, private database endpoints (e.g. db.internal).

Route 53 Alias Records vs Standard CNAME:

Feature Standard CNAME Record Route 53 ALIAS Record (AWS Specific)
Root Apex Support❌ No (Cannot create CNAME for example.com).✅ Yes (Can point example.com to ALB / CloudFront).
Query BillingCharged for DNS queries.Free of charge when pointing to AWS resources!
Dynamic IP TrackingPoints to hostname only.Automatically tracks changing AWS resource IPs.

23 & 24. DNS Diagnostic CLI Commands & Troubleshooting Troubleshooting

DNS CLI Tools
# 1. Lookup IPv4 A records using nslookup (Windows / Linux / macOS)
nslookup example.com

# 2. Query specific nameserver
nslookup example.com ns-123.awsdns-15.com

# 3. Comprehensive DNS trace using dig (Linux / macOS)
dig example.com +trace

# 4. Query specific record type (MX, TXT, CNAME)
dig example.com MX +short
dig example.com TXT +short

# 5. Flush local DNS cache
# Windows:
ipconfig /flushdns
# macOS:
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

26. 40+ DNS & Route 53 Interview Questions & Answers Interview Q&A

# Interview Question Short & Technical Answer
1What is DNS?A hierarchical distributed naming system that translates human-readable hostnames into IP addresses.
2What is an A Record?Maps a hostname to an IPv4 address.
3What is an AAAA Record?Maps a hostname to an IPv6 address.
4What is a CNAME Record?Maps an alias domain name to a canonical domain name (cannot be created on zone apex).
5What is an Alias Record in Route 53?An AWS-specific extension that allows mapping apex domains (e.g. example.com) directly to AWS resources (ALB, CloudFront) for free.
6What is a Hosted Zone?A container for DNS records that defines how traffic is routed for a domain name.
7Public vs Private Hosted Zone?Public is accessible across the internet; Private is resolved only inside specified AWS VPCs.
8What is TTL in DNS?Time To Live: duration in seconds that intermediate resolvers cache DNS records.
9What is Latency-based Routing?Routes user queries to the AWS region that delivers the lowest network latency.
10What is Failover Routing?Automatically redirects traffic to a backup disaster recovery site when the primary endpoint health check fails.
11What is Weighted Routing?Distributes traffic between multiple endpoints based on assigned percentage weights.
12What is Geolocation Routing?Routes traffic based on the physical geographic origin (continent/country) of the visitor.
13What port does DNS use?Port 53 (UDP for standard lookups, TCP for responses > 512 bytes and zone transfers).
14What is an MX record?Mail Exchange record specifying incoming mail servers for a domain.
15What is a TXT record?Stores text data used for SPF, DKIM, and domain ownership verification.
